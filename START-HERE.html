Apex Computers

No software to install. Open locally, upload to GitHub, then connect Vercel.

Open the websiteCreate GitHub repository

1. Test on this computer

  1. Extract the ZIP.
  2. Open the extracted apex-computers folder.
  3. Double-click index.html.

No Node.js, npm, VS Code, Git or local server is needed. Calls and normal SMS use your phone, WhatsApp needs internet, and email forms work after Vercel and Gmail are connected.

2. Upload with the GitHub website

  1. Create an empty repository named apex-computers.
  2. Upload the loose files and the small api, assets, data and lib folders first.
  3. Upload media-01, media-02 and media-03 one folder at a time.
  4. Commit each upload. Make sure index.html appears at the repository's top level.

3. Connect Vercel

  1. Open vercel.com/new and import the GitHub repository.
  2. Select Other as the framework.
  3. Leave the build command and output directory empty/default.
  4. Click Deploy.

4. Gmail is optional

The website works with calls, WhatsApp and normal SMS immediately. For email enquiries, add the five private Gmail settings listed in README.md to Vercel. Never upload a Gmail password to GitHub.
